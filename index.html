Syntax Reference

LWON documents consist of two main parts: Schema and Data Body. The Schema defines the structure of the data; the Data Body represents the actual values in the order defined in the schema.

Full Example
// Section 1: Schema (id, name, nested object, and arrays)
id name settings[theme] [orders[id total]] [tags]
// Section 2: Data Body (records as arrays within a root array)
[
[ 101 "John" ["dark"] [[5001 75.5] [5002 120]] ["vip" "ai"] ]
[ 102 "Alice" ["light"] [[5003 440]] {} ]
]
Schema Rules:
  • key: Simple field
  • [key]: Simple array
  • key[sub]: Single object
  • [key[sub]]: Array of objects
  • [key[@Ref]]: Recursive array
Data Rules:
  • Values follow the schema order.
  • Each record is an array [...].
  • Main body is inside a root array [...].
  • Recursive data is represented with natural nesting [...].

Data Types

TYPE DESCRIPTION LWON EXAMPLE
text_fields String
Used for text data. Written between standard double quotes.
"Hello World"
numbers Number
Integers and decimal numbers are written directly. Negative values are supported.
42.5
-1200
toggle_on Boolean
Logical values are written as true or false.
true
event Date
Date and time data are written between double quotes in ISO 8601 format.
"2026-02-16"
"2026-02-16T14:30:00Z"
not_interested Null
Used for undefined values.
{}
data_array Array
Array or list data is held within square brackets. Empty arrays are shown as {} just like other empty types.
["premium" "ai"]
{}

Primitive Arrays (Tags)

LWON

[

]

Conversion Detail

tags (full)
JSON Array ["p", "a"]

Null/Empty {}

Note: Primitive arrays (string array, number array etc.) are automatically serialized as space-separated values within square brackets.

Recursive Rules

@ Refers to the root schema. @name Refers to the named root wrapper. [field[@]] Recursive array.
Recursion Ideal for menus, trees, and categories.

Data body remains unchanged. Recursive structures are naturally represented as nested [...] in the data.

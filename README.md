# LWON Studio

The website for [LWON](https://github.com/ahmetzencirli/lwon), Lightweight Object
Notation: a home page, a two-way playground with live token counts, docs, the
specification, a guide for using LWON with AI models, and benchmarks.

Built with [Astro](https://astro.build) as a static site. Pages ship no
JavaScript unless they need it; the playground's tokenizer loads in a Web Worker.

## Develop

The site vendors the LWON library, spec and benchmark data from a sibling
checkout of the `lwon` repository until the `lwon` package is on npm:

```
workspace/
  lwon/          github.com/ahmetzencirli/lwon
  lwon-studio/   this repository
```

```bash
npm install
npm run sync      # copy library, SPEC.md and bench results from ../lwon
npm run dev       # http://localhost:4321
npm run build     # type-check and build to dist/
```

Files under `src/lib/lwon/`, `src/content/spec.md`, `src/data/bench.json` and
`src/data/samples/` are generated by `npm run sync`; edit them in `lwon`.

## Accessibility

Targets WCAG 2.2 AA: semantic landmarks, a skip link, visible focus, 44px touch
targets, light and dark themes that both pass contrast checks, and motion that
stops under `prefers-reduced-motion` and can be paused.
